programdemos/apply.xtl

Calling a function of several arguments, three ways (docs/several-arguments.md). Every X_eTaL function takes one argument: x f y is (f x) y, so a third argument goes to the function that call gives, as an applied group (...) z.

Run it with ./demos/apply.xtl or "xetal run demos/apply.xtl"; each way prints 4321. "xetal expand demos/apply.xtl" shows what the macro of the second way wrote.
