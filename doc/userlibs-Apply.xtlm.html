macro libraryuserlibs/Apply.xtlm

A macro library of your own (userlibs/, as Repeat is): a function applied to several arguments, written as one call. Every X_eTaL function takes one argument, so a call with more is a chain of applied groups, ((a f b) c) d; this macro writes that chain for you when the program is expanded. Import it with an alias of your choice, "ap:" u_se< "Apply", and see what a call becomes with xetal expand FILE. The idiom for a function of more than two arguments is a tuple (f (a, b, c, d)); this library shows what a macro can write.

ᵐa̲pply< : Char -> Char -> Char

macro · line 25

The function on the left applied to the arguments on the right, separated by ◆ (a space would make one array of them): the first is its left argument, the second its right, and each one after that is passed to the function the call so far gives, as (...) next. One argument is a plain call. The pieces are copied as written, each in parentheses.
