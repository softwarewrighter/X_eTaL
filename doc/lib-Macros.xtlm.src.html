A 2⍝│ macro is an ordinary function of the source text written on each 3⍝│ side of its call; the text it gives replaces the call, then is read 4⍝│ as code. Import it with an alias of your own, "x:" u_se< "Macros", 5⍝│ and see what a program becomes with xetal expand FILE.
