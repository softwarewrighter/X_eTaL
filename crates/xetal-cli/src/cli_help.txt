STAGES:
  Every stage reads source given with -e EXPR or as a FILE path and
  prints deterministic text:
    lex     token stream (decoration decides each token's class)
    render  decorated Unicode form (--raw converts back)
    parse   surface AST, or an ambiguity report listing every parse
    fmt     canonical, fully parenthesized form
    core    Core IR after desugaring
    type    inferred type
    eval    result value
  A stage that is not implemented yet exits 1 with
  error[unsupported].

EXAMPLES:
  xetal eval -e '1 + 2'
  xetal lex -e 'square = { _r * _r }; square_ 7'
  xetal run demos/life.xtl

AI CODING AGENT INSTRUCTIONS:
  1. The language is defined by its tests: spec/**/*.case (run by
     `cargo test`), crate tests, and reg-rs baselines in reg/.
  2. Check one expression at every stage with
       xetal lex -e EXPR; xetal parse -e EXPR; xetal eval -e EXPR
  3. Ambiguous source is an error that lists the parses; never pick
     one. Errors are printed as error[CODE]: MESSAGE on stderr.
  4. Run scripts/gate.sh (fmt, clippy, tests, reg-rs, markdown,
     sw-checklist) before claiming a change is done.
