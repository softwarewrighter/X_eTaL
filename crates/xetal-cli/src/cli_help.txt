STAGES:
  Every stage reads source given with -e EXPR or as a FILE path and
  prints deterministic text; each runs the earlier stages first:
    lex     token stream with byte spans
    render  decorated Unicode form; --raw converts decorated text
            back to source, --latex prints LaTeX math
    parse   surface tree as S-expressions (at most one reading;
            ambiguous shapes are errors)
    fmt     canonical, fully parenthesized form
    core    Core IR after desugaring (built-ins marked #)
    type    inferred type of each top-level item
    eval    type-check, then evaluate; prints each top-level
            expression's value (--untyped skips the checker)
    run     type-check and run a .xtl script (also: xetal FILE, for
            #! scripts; --untyped skips the checker)
  A stage that is not implemented yet exits 1 with
  error[unsupported]. Warnings print as warning[CODE] on stderr.

EXAMPLES:
  xetal eval -e '1 + 2'
  xetal eval -e 'u:s_quare := { _r * _r }; u:s_quare 7'
  xetal lex -e 'u:s_quare := { _r * _r }; u:s_quare 7'
  xetal type -e 'u:s_quare := { _r * _r }'
  xetal render -e 'o_-_12 x^2'
  xetal render --latex -e 'o_-_12 x^2'
  xetal run demos/factorial.xtl
  xetal run --untyped demos/fixed-point.xtl
