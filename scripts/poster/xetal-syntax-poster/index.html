Syntax you can see

Typography carries semantic information.

1. Name decorations

A glance tells you what a name is and where it came from.
Underlined first character → function
Superscript → provenance / namespace
No underline → value / variable

2. Import a library

The alias becomes visible wherever an imported name is used.
Typed: "c:" u_se< "Combinators"
Seeing superscript ᶜ tells the reader which import to find.

3. Definitions

Functions, variables, binding, and lambdas.
← binds (typed :=); = compares. A variable takes no u: prefix.

4. Apply or pass?

Juxtaposition applies; quote passes a function value.
apply f to x
pass f as a value
Higher-order functions replace a separate operator class.

5. Axes

Subscripts visually attach axes to the function they modify.
default axis · axis 2 · axes 1 and 2
transpose: every axis reversed · axes 2 and 3 swapped

6. Power

Superscript means numeric power or repeated function application.
value exponent
apply life four times

7. Lambdas

Braces define an anonymous function.
⍺ (typed _l) left argument
⍵ (typed _r) right argument

8. System names

APL quad marks system facilities; function decoration still applies.
read a file · write a file · read a typed line · draw cells · draw a line · show a picture
Rendered form only: no literal underscore or [] appears here.

9. The ? symbol

Context distinguishes a guard delimiter from punctuation in a name.
a guard: when n ≤ 1, the result is 1; ◆ (typed ;) separates statements
No user-defined operator class: compose behavior with ordinary higher-order functions.
