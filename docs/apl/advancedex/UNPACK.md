# UNPACK

From ADVANCEDEX, Appendix B (Advanced Examples) of the APL\360 User's
Manual: the March 1970 edition (GH20-0683-1), page B.2; the August 1968
edition, page B.2, prints it the same.

What it does, from the manual: the inverse of PACK: it turns the single
number back into serial number, month, day and year (by encode).

```
    &#8711; Z&#8592;UNPACK X
[1]   Z&#8592;1+ 10000 12 31 100 &#8868;X
    &#8711;
```

The example is in [PACK](PACK.md).
