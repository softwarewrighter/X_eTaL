# F

From ADVANCEDEX, Appendix B (Advanced Examples) of the APL\360 User's
Manual: the March 1970 edition (GH20-0683-1), page B.9; the August 1968
edition, page B.9, prints it the same.

What it does, from the manual: the function whose root ZERO seeks: a specific polynomial
(coefficients &#175;20 18 3 &#175;5 1, ascending, evaluated with PO), which can be
replaced by any desired function.

```
    &#8711; Z&#8592;F X
[1]   Z&#8592; &#175;20 18 3 &#175;5 1 PO X
    &#8711;
```

The example is in [ZERO](ZERO.md).
