## Breaking changes

- **code strings are checked: say code in ## takes:, write c"..." where code is taken** (423ccdeb, 2026-10-18): a code string `c"..."` whose inside is not X_eTaL (a format string, an equation) is now an error: make it a plain string; `xetal lint --fix` adds or drops the `c` where a macro's `## takes:` says code or text.
- **write a library's helpers with h:** (1d75a321, 2026-10-07): a library's bare top-level function warns `deprecated-private` and becomes an error after one release: run `xetal migrate FILE` on each library and keep its output (helpers written `h:`).
- **a name is bound once: write a! for one that changes, _ := for a value you discard** (1a77fe68, 2026-10-09): binding a name twice in one scope is `error[rebind]`: write `_ := ...` for a value kept only for its effect, `s! := ...` for state that changes, or rename a reused temporary.

## Notices

- **Interactive programs in a page: xetal_play::Interactive, no replay**
- **t_anh, s_qrt, e_xpm1, l_og1p, e_rf and e_rfc are built-ins: drop private versions**
- **an unused parameter is _u: drop # lint: allow unused-binding**

Each notice's text is in `docs/asks.md`.

## Landed: drop the workaround

- E2 (landed): `.xtlm` macro libraries (the same as X1). Here: the macros lane: `.xtlm` libraries found with `u_se<`, `m:n_ame<` macros run when the program is expanded (MC10-MC12, MC23); the example `lib/Macros.xtlm`
- E3 (landed): the CLI as a library: a host entry point so a host can be `xetal` with its own store. Here: step 145 (cli-library): the crate `xetal-command` (components/cli): `parse` reads the arguments as the binary does, `run` runs a command against a `Host` (its files through the `Files` trait, its output and error streams, a seed); the `xetal` binary is a thin shell over it, and the browser's terminal uses it too
- E4 (partly landed): the time: a quad for the current time and a monotonic or CPU clock. Here: `[]TS` (the local time stamp) and `[]D_L` (a delay), through the host's clock (D84, quads lane step 2); no monotonic or CPU clock (APL's quad AI) yet, not planned
- E6 (landed): `xetal --draw DIR run FILE` failed: options before the subcommand. Here: 5f00608 (options before the subcommand)
- E7 (landed): `xetal type FILE` calls a library whose `l:` names all come from macro calls a program: it decides before expanding. Here: step 087 (D128): `xetal type`, `run` and `doc` decide a file is a library after its macros expand (`is_library_named`)
