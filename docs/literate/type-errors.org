#+TITLE: Type errors, read
#+SUBTITLE: the common mistakes, the errors they give, and the fixes
#+AUTHOR: Michael A Wright
#+OPTIONS: toc:2 num:nil ^:{}

X_eTaL checks the types of a whole program before it runs any of it.
When a check fails, the error says where, as a file, a line and a
column, shows the line with the place underlined, and, for a type
mismatch, says where each side got its type: a binding, a literal, or a
built-in whose result is always one type. A common mistake also gets a
~help:~ line that says what to write instead.

Each section below is one mistake: a short wrong program, the error
~xetal run~ gives for it, and the program fixed. The programs are the
files in ~docs/literate/type-errors/~, and the goldens
~type-errors-*~ (in ~reg/~) run each one, so the errors shown here are
the ones ~xetal~ gives today.

* Reading an error

An error has four parts:

- the first line: ~error[CODE]: MESSAGE~, the code stable and the
  message in words;
- ~--> FILE:LINE:COLUMN~ and the line itself, the place underlined in
  ~^~;
- labels, underlined in ~-~: other places that explain the error, each
  with what it says there;
- notes (~= note:~) and hints (~= help:~).

The same text appears in the CLI, the REPL (where the file is ~repl~
and the lines are those you typed), the editor and the live demo, which
also mark the place in the drawn source.

* Int and Float mixed

A name has one type. ~/~ always gives a Float, so ~m~ is a Float, while
~k~, bound to a whole number, is an Int; ~+~ takes two numbers of one
type. The error points at the sum, says what each side is, and shows the
two bindings that gave them their types.

#+begin_example
m := 7 / 2
k := 1
k + m
#+end_example

#+begin_example
$ xetal run type-errors/int-and-float.xtl
error[type-mismatch]: expected Int, found Float
 --> type-errors/int-and-float.xtl:3:1
  |
3 | k + m
  | ^^^^^
  | - `k` is an Int
  |     - `m` is a Float
  |
1 | m := 7 / 2
  |      ----- `m` gets its type here: `/` always gives a Float
  |
2 | k := 1
  |      - `k` gets its type here
  = note: `+` has type Num a => a -> a -> a
  = help: Int and Float do not mix: `f_loat n` makes a Float of an Int, `f_loor x` or `c_eiling x` an Int of a Float
#+end_example

Convert one side: ~f_loor~ (or ~c_eiling~) makes an Int of a Float,
~f_loat~ a Float of an Int.

#+begin_example
m := f_loor 7 / 2
k := 1
k + m
#+end_example

#+begin_example
$ xetal run type-errors/int-and-float-fixed.xtl
4
#+end_example

* A box where its value is wanted

~e_nclose~ puts its argument in a box, a single value that holds an
array. Arithmetic works on the numbers, not on the box.

#+begin_example
b := e_nclose 1 2 3
b + 1
#+end_example

#+begin_example
$ xetal run type-errors/boxed.xtl
error[type-mismatch]: expected a number, found Box Int
 --> type-errors/boxed.xtl:2:1
  |
2 | b + 1
  | ^^^^^
  | - `b` is a Box Int
  |
1 | b := e_nclose 1 2 3
  |      -------------- `b` gets its type here
  = note: `+` has type Num a => a -> a -> a
  = help: `d_isclose b` opens a box to get the value inside
#+end_example

Open the box with ~d_isclose~ first.

#+begin_example
b := e_nclose 1 2 3
(d_isclose b) + 1
#+end_example

#+begin_example
$ xetal run type-errors/boxed-fixed.xtl
2 3 4
#+end_example

* A function still waiting for an argument

~u:a_dd~ takes two arguments, one on each side. Given only the right
one, ~u:a_dd 2~ is a function waiting for the left, and ~+~ cannot add a
function.

#+begin_example
u:a_dd := { a b -> a + b }
1 + u:a_dd 2
#+end_example

#+begin_example
$ xetal run type-errors/waiting.xtl
error[type-mismatch]: expected a number, found a -> a
 --> type-errors/waiting.xtl:2:1
  |
2 | 1 + u:a_dd 2
  | ^^^^^^^^^^^^
  = note: `+` has type Num a => a -> a -> a
  = help: this is a function still waiting for an argument: give it one, or quote it ('f_) to pass the function itself
#+end_example

Give it both arguments.

#+begin_example
u:a_dd := { a b -> a + b }
1 + 2 u:a_dd 3
#+end_example

#+begin_example
$ xetal run type-errors/waiting-fixed.xtl
6
#+end_example

* A function passed without its quote

To pass a function as a value, to ~m_ap~ for instance, quote it.
Unquoted, ~u:t_wice m_ap 3 4~ applies ~u:t_wice~ to the map's result,
and ~m_ap~ is given a number where it wants a function.

#+begin_example
u:t_wice := { x -> 2 * x }
u:t_wice m_ap 3 4
#+end_example

#+begin_example
$ xetal run type-errors/quote.xtl
error[type-mismatch]: expected a -> b, found a number
 --> type-errors/quote.xtl:2:10
  |
2 | u:t_wice m_ap 3 4
  |          ^^^^^^^^
  = note: `m_ap` has type Any b => (a -> b) -> a -> Box b
  = help: a value is applied as if it were a function: is there an argument too many, or a function passed without its quote?
#+end_example

Quote the function: ~'u:t_wice~.

#+begin_example
u:t_wice := { x -> 2 * x }
'u:t_wice m_ap 3 4
#+end_example

#+begin_example
$ xetal run type-errors/quote-fixed.xtl
┌→────────┐
│ ┌─┐ ┌─┐ │
│ │6│ │8│ │
│ └~┘ └~┘ │
└∊────────┘
#+end_example

* A Float as a condition

A guard's condition is a Bool or an Int (zero is false). A Float is
neither.

#+begin_example
u:s_ign := { x -> x ? 1; 0 }
u:s_ign 0.5
#+end_example

#+begin_example
$ xetal run type-errors/condition.xtl
error[type-mismatch]: expected Bool or Int, found Float
 --> type-errors/condition.xtl:2:1
  |
2 | u:s_ign 0.5
  | ^^^^^^^^^^^
  |         --- a Float literal
  = help: a Float is not a condition or a count: `f_loor x` makes an Int of it, a comparison (`x > 0`) a Bool
#+end_example

Compare to get a Bool, or round to an Int.

#+begin_example
u:s_ign := { x -> x > 0 ? 1; 0 }
u:s_ign 0.5
#+end_example

#+begin_example
$ xetal run type-errors/condition-fixed.xtl
1
#+end_example

* A string where a number is wanted

A string is a vector of characters, so ~"2"~ is text, not the number 2.

#+begin_example
n := 1 + "2"
n
#+end_example

#+begin_example
$ xetal run type-errors/string.xtl
error[type-mismatch]: expected a number, found Char
 --> type-errors/string.xtl:1:6
  |
1 | n := 1 + "2"
  |      ^^^^^^^
  |          --- a string: a vector of Char
  = note: `+` has type Num a => a -> a -> a
  = help: a string is text, not a number: write a number without quotes
#+end_example

Write the number without quotes.

#+begin_example
n := 1 + 2
n
#+end_example

#+begin_example
$ xetal run type-errors/string-fixed.xtl
3
#+end_example

* A name bound twice

Values are immutable: a name without ~!~ is bound once in its scope.
Binding it again is an error that says what to write.

#+begin_example
total := 0
total := total + 5
total
#+end_example

#+begin_example
$ xetal run type-errors/rebind.xtl
error[rebind]: total is already bound in this scope: a name is bound once; write total! for a variable that changes
 --> type-errors/rebind.xtl:2:1
  |
2 | total := total + 5
  | ^^^^^^^^^^^^^^^^^^
#+end_example

A variable that changes is written with ~!~, every time it is used.

#+begin_example
total! := 0
total! := total! + 5
total!
#+end_example

#+begin_example
$ xetal run type-errors/rebind-fixed.xtl
5
#+end_example
