Cause: when a group of mutually dependent top-level definitions is complete, xetal-types infer.rs closes its members in HashMap key order (self.globals.keys()); closing a value defaults the shared numeric variables to Int (T5) while closing a function first generalizes them (they stay Num), so the order decides the type. Also the undefined-name check reports whichever Pending global the map yields first. Fix: close a group in a fixed order, its functions generalized first (in source order), then its values (as Haskell generalizes a binding group), and report the earliest undefined name.
