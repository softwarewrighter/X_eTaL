The user (2026-10-21): can the TUI warn when the terminal's font is not JuliaMono? A terminal never reports its font name, and the cursor advance after a probe string comes from the terminal's width tables, not the font, so a probe cannot tell. What can be known: whether JuliaMono is installed at all (font files under ~/Library/Fonts, /Library/Fonts, ~/.fonts, ~/.local/share/fonts, /usr/share/fonts; fc-list where fontconfig exists), and, for the known terminals (TERM_PROGRAM: iTerm2's plist, Terminal.app's profile, kitty.conf, alacritty.toml, wezterm.lua, VS Code's settings.json), which font the profile names. xetal edit and the REPL show one status-line hint on start when JuliaMono is not installed or the profile names another font ('drawn for JuliaMono: see Fonts in the README'), never an error; XETAL_NO_FONT_CHECK=1 or a settings flag silences it; a wrong guess is impossible to rule out, so the wording stays a hint.
