d_isplay (user request, like APL2 DISPLAY): a built-in giving a value as a boxed picture (Char matrix) showing rank, shape and the items with box-drawing characters and axis marks, typed a -> Char; built on xetal-grid; a --box switch for xetal run/show printing every top-level value boxed; in the live demo a Boxed toggle for the output. Decisions recorded with the user (names, marks), reference and idioms updated.
