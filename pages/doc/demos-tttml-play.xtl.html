programdemos/tttml-play.xtl

TTTML, part 2: play the machine that demos/tttml-train.xtl trained (run that first), with "xetal run demos/tttml-play.xtl". You are X and move first: type a square, 1 to 9, numbered row by row. Something that is not an empty square is asked for again. Uses the TTTML library (lib/TTTML.xtl).
