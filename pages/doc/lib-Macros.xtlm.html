macro librarylib/Macros.xtlm

A small macro library, an example of macros of your own (MC10). A macro is an ordinary function of the source text written on each side of its call; the text it gives replaces the call, then is read as code. Import it with an alias of your own, "x:" u_se< "Macros", and see what a program becomes with xetal expand FILE.

macro · line 34

The line "ok: label" when the condition on the left holds, else "FAIL: label (cond)", the condition shown as it was written, which a function, given only the condition's value, cannot do.

      ˣ⁼u̲se< "Macros"
      "5 = 2 * 2" ˣc̲heck< "doubling"
