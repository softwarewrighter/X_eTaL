librarylib/TTTML.xtl

TTTML: a machine that learns tic-tac-toe by playing itself (a standard library, built into xetal), ported from the TTTML workspace of sw-apl's library 1. Import it with an alias of your choice: "t:" u_se< "TTTML". docs/literate/tttml.org explains it; the demos demos/tttml.xtl, demos/tttml-train.xtl and demos/tttml-play.xtl use it.

A board is 9 numbers, the squares row by row: 1 for X, -1 for O, 0 for an empty square. X moves first, so the board says whose turn it is: X's when it sums to 0. What the machine learns is a model: two rows, the codes of the positions met and their values. Only the functions that roll dice end in !.
