librarylib/Combinators.xtl

Combinators: the birds Raymond Smullyan names in "To Mock a Mockingbird" that type-check (a standard library, built into xetal). Import it with an alias of your choice: "c:" u_se< "Combinators". docs/birds.md lists them all; the self-applying birds (L, M, M2, U) have no finite type and are in demos/birds-untyped.xtl.

Each bird only rearranges, repeats, drops or groups its curried arguments; its rule is given in Smullyan's notation, where B x y z = x (y z) means B applied to x, y and z gives x applied to (y applied to z).

How the definitions read: a x̲ b is x applied to a and then b (every function is curried); (e)_ v applies the function e computes; a function passed along as a value is quoted, 'y̲. In a call, quoted function arguments come first, the nearest operand being the bird's first argument: 'n̲eg 'a̲bs ᶜB̲ -5 is a_bs (n_eg -5).
