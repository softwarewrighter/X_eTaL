programdemos/macros.xtl

Macros write source for you: a call "left" n_ame< "right" is replaced, before the program is checked, by the source the macro writes from the two texts. Run it with ./demos/macros.xtl (or xetal run): it prints what the system macros give, then a macro library's checks; a failed a_ssert< goes to standard error. Read each call beside its expansion, which "xetal expand demos/macros.xtl" shows.
