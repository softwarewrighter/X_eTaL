programdemos/combinators.xtl

Combinators: the Combinators library, Smullyan's birds, each a function that only rearranges, repeats or drops its arguments. Run it with "xetal run demos/combinators.xtl" (or "./demos/combinators.xtl"), or as a notebook with "just show demos/combinators.xtl"; it prints what each bird makes of small numbers, ending with 10 factorial from Y and 1024 from a function power. docs/birds.md lists every bird.
