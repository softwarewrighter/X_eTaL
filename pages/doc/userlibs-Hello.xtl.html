libraryuserlibs/Hello.xtl

Hello: the smallest library, one greeting. A library is an ordinary file whose exported names start with l:; libraries of your own live in userlibs/, on the search path. demos/hello-library.xtl imports it ("hi:" u_se< "Hello"), and docs/literate/hello.org walks through both. The name in the string is the logo: typed X_ e:T a:L, drawn, spaces removed (a string may hold any Unicode).
