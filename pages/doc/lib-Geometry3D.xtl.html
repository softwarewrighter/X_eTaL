librarylib/Geometry3D.xtl

Geometry3D: points in space as arrays (a standard library, built into xetal). Import it with an alias of your choice: "g:" u_se< "Geometry3D". Points are a 3-row matrix, x over y over z, one column per point, as []P_ATH takes 2 rows; a rotation is a 3 x 3 matrix, and turning the points is one inner product. A face is a 3 x 4 matrix of corners, and a solid is faces stacked along a new first axis (F x 3 x 4), so one expression orders them far to near for painting. Names with l: are exported; names with h: are private to this file.
