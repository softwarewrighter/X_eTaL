programdemos/monads.xtl

The Maybe monad from the Maybe library: computations that can fail, chained so that the first failure stops the chain.

Run it with ./demos/monads.xtl or "xetal run demos/monads.xtl", or as a notebook with "just show demos/monads.xtl". Each line prints a result, or the default (-1, or 0 for m_aybe) where a division by zero emptied the maybe. Read how b_ind chains steps right to left.
