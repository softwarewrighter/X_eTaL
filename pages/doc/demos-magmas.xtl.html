programdemos/magmas.xtl

Magmas: a set with a binary operation that stays in the set, and nothing more is promised. Rock-paper-scissors is one: x played against y gives the winner (x on a tie). With its table we can ask which laws hold, for every case at once.

Run it with ./demos/magmas.xtl or "xetal run demos/magmas.xtl". It prints the Cayley tables of rock-paper-scissors and of its five-move extension, a 1 or 0 for each law checked, and draws the five-move table as an SVG file. Read the law checks: each is one comparison over a whole table, with no loop.
