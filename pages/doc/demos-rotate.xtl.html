programdemos/rotate.xtl

Rotate along both axes: every frame moves the arrow one row down and one column right, wrapping around the edges of the board.

Run it with ./demos/rotate.xtl or "xetal run demos/rotate.xtl". It prints eight frames separated by a blank line ("just animate" plays them). Read -1 o̲-₁₂ b: one rotation along axes 1 and 2 together.
