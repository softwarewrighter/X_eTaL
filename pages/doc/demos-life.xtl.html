programdemos/life.xtl

Life: Conway's Game of Life in one line, u:l_ife, then a blinker and a glider run through it. Run it with "xetal run demos/life.xtl" (or "./demos/life.xtl"); it prints a blinker after one and two steps, 1s showing that two steps restore it, then a glider's five generations a blank line apart. Read u:l_ife for reduce and rotate along both axes at once (the _12 subscripts).

The rules

ᵘl̲ife : (Num a, Truthy a) => a -> a

function · line 15

u:l_ife board: the next generation of a 0/1 board. The board ⍵ rotated by every offset in -1 0 1 along both axes and summed gives S, each cell plus its neighbors; a cell lives next when S is 3, or when it is alive and S is 4.
