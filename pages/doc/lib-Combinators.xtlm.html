macro librarylib/Combinators.xtlm

Combinators as macros: the birds of the Combinators library written in at compile time instead of applied when the program runs. Import both under one alias: "c:" u_se< "Combinators" finds Combinators.xtl (c:Y_, c:B_, ...) and this file (c:Y_<, c:B_<).

ᵐY̲< : Char -> Char -> Char

macro · line 17

Define the function named on the left by the lambda on the right, whose first parameter is the function itself: the knot c:Y_ ties when the program runs is tied here, by writing the name in place of the self parameter. The result is plain named recursion, with no lazy parameter and no combinator left to run.
