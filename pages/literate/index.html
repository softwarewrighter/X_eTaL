Literate documents

Worked examples written in Org mode: prose and X_eTaL blocks, each block run by xetal through ob-xetal in Emacs and its result recorded under it.

  • A literate tour of X_eTaL
    every feature of the language, run as you read
  • Hello, library
    writing a library of your own, and using it
  • Life in one line
    Conway's Game of Life in X_eTaL, built up a piece at a time
  • Libraries
    what a library is, and the standard libraries at work
  • The aviary: combinators in X_eTaL
    Raymond Smullyan's birds as a library, run as you read
  • TTTML: a machine that learns tic-tac-toe
    learning by playing itself, in X_eTaL
  • Classic APL programs, drawn
    Pascal's triangle, Life and turtle graphics in X_eTaL, with their pictures
  • The Tower of Hanoi, three ways
    recursion, currying with combinators, and every move at once

XeTaL in LaTeX: every line of code we ship or document, as xetal render --latex writes it and KaTeX draws it.

The Org sources are in the repository's docs/literate/, with the Emacs mode and ob-xetal in docs/emacs/.
