macros-hygiene (decided with the user 2026-10-04): automatic, Scheme-like hygiene with declared anaphora. After a macro returns its text the macro phase parses the expansion and finds each name it binds around text copied from the call's arguments (a lambda parameter, or a binding inside an introduced { }), telling copied text from added text by the byte map; every such binder the macro introduced is renamed to a fresh name, except names the macro declares in its doc comment as "## binds: it" (anaphora, e.g. "xs" a_if< "it + 1"). Fresh names use a namespace prefix reserved for the macro phase (spelling proposed), numbered deterministically in expansion order; a program or library writing it is rejected; errors naming a fresh name map back to the call. xetal expand shows the renamed names; tell main the exact binds: syntax for xetal doc.
